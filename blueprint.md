# **App Name**: AuraTime

## Core Features:

- Intelligent Temporal Assistant: A natural language interface that acts as a tool to automatically set complex alarms and timers from text prompts.
- Global Multi-Alarm Manager: Configure multiple alarms with custom labels and high-fidelity melodic presets.
- Cosmic Precision Stopwatch: High-precision lap tracking with a millisecond-accurate display for fitness or productivity tracking.
- Dynamic Countdown Engine: A visually immersive timer with smooth transitions and status updates for active sessions.
- Professional Logic Calculator: A minimal, modern calculator with clear history displays and algebraic priority support.
- Real-time World Chronometer: A primary timekeeping dashboard featuring local time, date, and day visualization.

## Style Guidelines:

- Primary Color: #67B0F9 (a vibrant cosmic blue) chosen to represent technical precision and the infinite sky.
- Background Color: #0B0E14 (heavily desaturated deep space midnight) providing high contrast for glowing interface elements.
- Accent Color: #67F9EC (a cyan-toned aquatic accent) used for active states and critical calls-to-action.
- Headlines and numeric displays use 'Space Grotesk' for its tech-forward, futuristic feel; 'Inter' is used for UI labels for maximum readability.
- Calculations and digital time strings use 'Source Code Pro' to provide a monospaced, machined look appropriate for clock data.
- A modern glassmorphic approach utilizing blur backdrops (24px) and subtle borders (1px) to separate tool cards.
- Micro-interactions include glow pulses on active digits and subtle elastic slide transitions between main application tabs.
